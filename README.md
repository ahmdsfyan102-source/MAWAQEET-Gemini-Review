# مَواقيت — MAWAQEET (كفر الشيخ، مصر) v3.0.4

تطبيق ويب عربي كامل (`RTL`) مبني بـ **React + TypeScript + Vite + Tailwind CSS v4**، يقدم مواقيت الصلاة الفلكية لمدينة كفر الشيخ وفق الهيئة المصرية العامة للمساحة، مع إدارة المواعيد والدروس، والتقويم الهجري (أم القرى) والميلادي، وقارئ الأذكار الشامل، والسبحة الإلكترونية، والتنبيهات الصوتية.

## التشغيل المحلي والاختبار

```bash
npm install
npm run dev      # يعمل على المنفذ 3000 (http://0.0.0.0:3000)
npm run build    # فحص TypeScript وبناء الإنتاج
npm run lint     # التحقق عبر tsc --noEmit
npx tsx --test src/domain/*.test.ts
```
